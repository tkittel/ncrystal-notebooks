Logo files for the website, copied unchanged from
https://github.com/mctools/ncrystal-logo (commit 4a5cc3d6934e), which is under
the Apache License 2.0 (see the LICENSE file and the usage note there):

* ncrystal-logo.svg and ncrystal-logo-dark.svg (from svg/): the logo in the
  sidebar, for the light and dark themes.
* favicon.svg (from web/): the favicon, which switches between light and dark
  by itself.

The notebooks themselves refer to the logo by URL instead (see LOGO_URL in
devel/pypath/ncnb_devtools/expand.py), since they are also opened on their own,
e.g. in Google Colab.
